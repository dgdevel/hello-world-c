# examples

small runnable scripts showing the subcommands of `hello-world-c`.
run any of them from the repo root after `make`:

    ./examples/scripts/<name>.sh

## scripts

- `help-version.sh` - print the built-in help and the version stamp
- `hello.sh` - the greeting: bare, and with a name argument
- `echo.sh` - echo arguments, then pipe a line of stdin through with `-`
- `reverse.sh` - reverse arguments, then reverse stdin with `-`
- `wc.sh` - count lines, words and bytes of a stdin sample
